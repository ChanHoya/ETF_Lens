# Product Definition — ETF Lens

## Vision

한국 개인 투자자가 ETF를 비교하고 포트폴리오를 관리할 수 있는 **올인원 ETF 인텔리전스 플랫폼**.
기존 ETFcheck 등의 단순 정보 제공을 넘어, 실질 보수(TER+매매비용), 종목 중복도, 실시간 KIS 연동 포트폴리오 추적까지 제공한다.

## Goals

1. **ETF 심층 분석**: 실질 TER, 샤프지수, MDD, 수익률 비교 (1M/3M/6M/1Y)
2. **포트폴리오 추적**: KIS API 연동으로 4개 계좌의 잔고/손익/수익률 실시간 조회
3. **TFF 대시보드**: 엑셀 업로드 기반 특정 펀드(TFF) 월별 성과 시각화
4. **AI 마켓 인텔리전스**: Gemini API 기반 ETF 추천, 매크로 분석, Exit Signal
5. **초기 투자금 대비 수익률**: KIS 자동 + 수동 입력 두 방식으로 실제 투자 수익 추적

## Non-Goals (v1 범위 외)

- 주문 실행 (매수/매도) — 조회 전용
- 해외 ETF (미국/유럽) 직접 분석 — KIS 해외 잔고 표시만 지원
- 모바일 네이티브 앱 — 반응형 웹만

## Target Users

**주 사용자**: 1인 운용 투자자 (펀드 매니저 포함) — KIS 계좌 보유, ETF 중심 투자

**구체적 페르소나**:
- 월 1~2회 리밸런싱하는 ETF 장기 투자자
- TFF 같은 소규모 펀드를 엑셀로 관리하던 매니저
- 여러 계좌의 포트폴리오를 한 화면에서 보고 싶은 투자자

## Key Metrics (성공 기준)

- 포트폴리오 조회 응답 시간 < 30초 (KIS API 4계좌 순차 조회)
- ETF 마스터 DB: 1,000+ 종목 커버
- 예수금/수익률 정확도: KIS 앱과 ±0.1% 이내
