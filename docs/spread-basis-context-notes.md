# 장단기 금리차 기준 통일 — 컨텍스트 노트 (2026-10-05)

## 왜 10년−3년인가
- 한·미를 한 차트에 놓으려면 같은 만기 간격이어야 한다. 10년−3개월(약 10년 간격)과 10년−3년(7년 간격)은 같은 상황에서도 크기가 다르다.
- 후보별 데이터 확인(ECOS 817Y002·FRED) 결과는 다음과 같다.
  - 10년−3년: 국고채 3년 1998-11~, 미국채 3년(DGS3) 1962~. 두 나라 모두 국채로 20년 이상 비교할 수 있다. → 채택.
  - 10년−2년: 국고채 2년이 2021-03부터라 이력이 짧다. 통안증권 2년은 국채가 아니다.
  - 10년−3개월: 한국 3개월은 CD 91일(은행 예금증서)이라 신용·유동성 위험이 섞인다.
- 2006~2026 미국 일별 기준으로 10년−2년과 10년−3년의 상관은 0.993이고 평균 차이는 0.13%p다.
  같은 기준선을 두면 10년−2년은 중복이라 화면에서 뺀다.
- 미국 10년−3개월은 뉴욕 연준 침체 확률 모델이 쓰는 기준이라 "참고"로 남긴다(상관 0.912, 성격이 다소 다름).

## 구현 메모
- us10y·us3y를 장기(50년) 수집 대상(LONG_FRED)에 넣는다. 미국 10년−3년 역전 이력도 1970년대 침체부터 연결된다.
  us10y의 다른 쓰임(카드 10년 백분위, 만기 비교, 곡선)은 모두 기간을 잘라 쓰므로 영향이 없다.
- 미국 곡선 형태(불/베어 스티프닝 등)도 3년·10년으로 바꾼다. 수익률곡선 점에 미국 3년을 추가한다.
- 종합 탭 유사 국면 특징 "미 10년−2년 금리차"는 내부 계산값이라 그대로 둔다(화면 비교선이 아님).
