# 시장동향 환율·금리 탭 2차 개선 컨텍스트 노트 (2026-10-05)

## 재진입 지연 원인
- Render는 uvicorn 단일 워커라 서버 메모리 캐시는 정상 재사용된다(연속 호출 0.25초).
- 지연은 프론트 쪽이다. 서브탭을 옮기면 FxTab·RatesTab이 언마운트되어 state가 사라지고, 다시 들어오면 로딩 화면부터 다시 그린다.
  Render 무료 인스턴스가 유휴 후 잠들었다 깨어나면 서버 캐시도 비어 20년 시계열을 다시 모으느라 수십 초가 걸린다.
- 해결: 모듈 메모리 + localStorage에 마지막 응답을 두고 즉시 그린다. 서버 기준 시각(updated_at)이 1시간을 넘었을 때만
  백그라운드로 다시 받는다(사용자 규칙: "갱신된 지 1시간 이상 경과된 콘텐츠만 업데이트"). 금리 탭의 이전 10분 규칙도 이 규칙으로 맞춘다.
- 서버 캐시 TTL이 1시간보다 길면 백그라운드 갱신이 같은 옛 데이터를 받아 오므로 환율 캐시를 30분으로 줄였다(금리 10분 유지).
- localStorage는 실패할 수 있어(사파리 사생활 보호·용량) try/catch로 감싸고 메모리 캐시만으로도 동작하게 한다.

## 초장기 금리 비교
- 구간: 단기 = 국채 1년(한·미 같은 상품), 장기 = 10년, 초장기 = 30년(한국 50년 `817Y002/010240000`, 2016~ 추가 표시).
- 해석 규칙(자동 문장):
  - 구간별 한−미 금리차와 1년 전 대비 변화.
  - 초장기 프리미엄(30년−10년): +0.3%p 이상이면 "재정·인플레 우려로 초장기 프리미엄 확대", 0 미만이면 "초장기 역전 — 연기금·보험사 장기채 수요 또는 저성장 기대".
  - 최근 1년 어느 구간이 가장 많이 올랐는지(단기 주도 = 정책금리 기대, 초장기 주도 = 기간 프리미엄).

## 타임라인 이정표
- Recharts 내부 좌표 API에 기대지 않고, 차트 아래 HTML 트랙을 플롯 영역(왼쪽 Y축 폭·오른쪽 여백)과 같은 폭으로 두고
  시간축이 선형(XAxis type=number, domain dataMin~dataMax, padding 0)인 점을 이용해 left %로 핀을 놓는다.
- 가까운 국면(예: 2025.04·2025.06)은 핀이 겹치므로 간격 4% 미만이면 다음 줄(최대 3줄)로 내린다.
- 차트에는 국면 밴드(연한 색)와 시작 지점 점선을 그리고, 선택한 국면만 진하게 칠한다. 기본 선택은 최신 국면.

## 서버 수집 지연(실서버 측정 후 추가)
- 배포 직후 실서버 첫 진입이 63초. Render에서 직접 재보니 수집만 환율 52초, 금리 96초(로컬 11초).
- 원인: 수집이 asyncio 기본 스레드 풀(CPU 수 + 4)에서 돌아 Render 소형 인스턴스에서는 10~22개 시계열이 몇 개씩 줄을 섰다.
  FRED는 전 기간 CSV를 받아 잘라 쓰고 있었다(DFF 2.6만 행).
- 해결(`core/overview_cache.py`): 전용 I/O 풀 16개로 동시 다운로드, FRED는 `cosd`로 필요한 기간만(행 수 약 70% 감소),
  만료된 캐시는 이전 값을 즉시 주고 뒤에서 재수집(동시 요청은 한 번의 수집 공유), 서버 시작 시 두 캐시 예열.
  응답에 `timings`(시리즈별 초)를 넣어 실서버에서 어느 원천이 느린지 바로 본다.
- 로컬 측정: 환율 1.2초, 금리 6.4초(ECOS 응답이 시리즈당 약 6초로 대부분).
