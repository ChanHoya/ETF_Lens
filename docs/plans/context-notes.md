# Sprint 42 UI/UX 표준 템플릿 아키텍처 의사결정 노트 (Context Notes)

## 1. 상단 네비게이션 1줄 축소(Minimize) 인터랙션 설계
- **문제 인식**: 메인 메뉴와 서브 메뉴가 상하 2단으로 상시 노출되면 모바일 및 일반 랩톱(13~14인치) 환경에서 차트와 테이블이 시작되는 수직 공간이 과도하게 좁아진다.
- **해결 방안**:
  - 서브메뉴가 있는 탭(예: 시장동향 하위 '시장지표', '종합', '환율' 등)에 진입하면, 메인 메뉴는 오른쪽 끝으로 부드럽게 축소(collapse)되어 `< >` 기호가 들어간 세련된 원형 캡슐 버튼으로 바뀐다.
  - 서브메뉴가 메인메뉴가 있던 윗줄 위치로 슬라이딩되어 올라오며, 전체 헤더가 1줄로 통합된다.
  - 사용자가 `< >` 버튼을 클릭하면 메인 메뉴가 다시 펼쳐져 다른 메인 탭으로 원클릭 전환할 수 있다.
  - `#iprism-headline`을 `sticky top-0 z-[180]`로 설정하여 스크롤다운 시에도 헤더가 상단에 항상 고정된다.

## 2. 팝업 모달 상단 헤더 보존형(Top-Anchored) 오버레이 설계
- **문제 인식**: 기존 모달은 `fixed inset-0`로 화면 전체를 덮어버려, 모달을 띄운 상태에서는 상단 네비게이션 메뉴를 볼 수 없고 닫기 버튼만 눌러야 했다.
- **해결 방안**:
  - 모달의 오버레이를 화면 전체가 아닌 상단 고정 헤더 바로 아래(`top-[56px] sm:top-[64px]`)부터 시작하도록 설정 (`top-[56px] sm:top-[64px] left-0 right-0 bottom-0`).
  - 모달 컨텐츠도 수직 중앙(`items-center`) 대신 상단 정렬(`items-start pt-3 sm:pt-4`)로 띄워, 사용자가 모달을 띄운 상태에서도 상단 메뉴의 현재 위치를 인지하고 시각적 안정감을 느끼도록 한다.

## 3. 차트 X축 연도 `'26` 축약 표준화
- **문제 인식**: 10개년, 3개년 시계열 차트에서 `2026-01-10`이나 `2026` 등의 4자리 연도가 빽빽하게 들어가면 X축 라벨들이 겹치거나 지저분해진다.
- **해결 방안**:
  - `chartDateUtils.ts`를 신설하여 `formatChartDate(dateStr)` 유틸 함수를 제공한다.
  - `2026-01-10` -> `'26/01/10`, `2026-10` -> `'26/10`, `2026` -> `'26`으로 정밀 축약하여 가독성과 공간 효율을 극대화한다.

## 4. 버튼 명칭 및 크기 표준화
- **명칭**: '데이터 갱신', '새로고침' 등 제각각이던 명칭을 전 서비스 `Update`로 통일.
- **크기**: 첨부 1, 2, 4, 5에 맞춰 `px-2.5 py-1 text-xs rounded-lg font-medium` 수준의 컴팩트 터미널 규격으로 일원화.
