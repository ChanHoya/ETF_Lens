# 3대 과제 의사결정 기록 (Context Notes)

## 1. 데이터 출처 폰트 및 스타일링 결정
- **결정 배경**: 사용자가 "모든 서비스에 빠짐없이 적용할 수 있도록 모든 메뉴 서브탭 서비스 및 개별 탭 기능 팝업 등 모든 화면에 있는 그래프 및 테이블에 출처 정보를 명기해줘", "출처 표기 폰트는 현재 적용된 것보다 더 작은 폰트로 해줘"라고 명시함.
- **스타일링**:
  - 기존 일부 차트 하단에 적용되었던 `text-[11px]`이나 `text-xs`(12px)는 카드 공간을 과도하게 차지하거나 본문과 경쟁하는 문제가 있었음.
  - 이를 해결하기 위해 극소형 마이크로 폰트인 `text-[9.5px]` (모바일 및 컴팩트 카드) ~ `text-[10px]` (기본)를 적용하고, 은은한 서브 텍스트 톤(`text-slate-400/80 dark:text-slate-500/80 font-mono tracking-tight`)으로 디자인 일관성을 확보함.
  - 재사용성을 극대화하기 위해 `DataSourceCaption.tsx` 공통 컴포넌트를 구축하고 `sources: string[]`, `updateFrequency?: string`, `align?: 'left' | 'right' | 'between'` 등을 유연하게 지원하도록 함.

## 2. DB 다중 산업 시계열 아키텍처 결정
- **결정 배경**: `IndustryMacroSeries` 테이블은 복합 기본키(`industry`, `date`)를 가지므로 단일 반도체에 국한되지 않고 다중 업종을 확장할 수 있도록 이미 준비되어 있었음.
- **적용 방향**:
  - `battery` (2차전지: 양극재/음극재 수출액, 단가, 물량, 가동률, 재고율)
  - `automobile` (자동차: 완성차 수출액, 친환경차 수출 비중, 부품 수출, 가동률, 재고율)
  - 10개년(2016~2026.10) 122개 월차 시계열을 SQLite DB에 시드 마이그레이션하여, 향후 반도체와 동일한 DB-First 구조로 타 섹터 분석 및 ETF 플레이북에서 활용할 수 있도록 기반을 마련함.

## 3. 텔레그램 속보 자동 알림 연동 방식 결정
- **결정 배경**: DB에 새로운 공표 데이터가 INSERT되거나 사이클 4국면 위치가 변경되었을 때, 사용자가 봇(`/semi`, `/macro`)으로 조회하거나 스케줄러가 속보를 발송할 수 있어야 함.
- **적용 방향**:
  - `telegram_bot.py`에 `/semi` 및 `/macro` 명령어 핸들러를 추가하여, 반도체 및 주력 수출업종의 펀더멘털 신호등, 최신 공표치, 사이클 사분면 국면을 즉시 전송함.
  - `semi_stats_sync.py`에서 신규 데이터 감지 시 비동기 텔레그램 속보 함수를 트리거하도록 연계함.
