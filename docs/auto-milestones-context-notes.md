# 이정표 자동 생성 컨텍스트 노트 (2026-10-05)

## 문제
국면 시작·끝·제목·배경을 코드 상수로 적어 두어, 새 국면(한은 방향 전환, 환율 추세 반전)이 생겨도 이정표가 생기지 않았다.

## 금리 — 경계 완전 자동
- 기준금리 변경을 방향(+/−)별로 묶는다. 같은 방향 변경이 이어지는 동안은 간격이 길어도 한 사이클(2012~2016 인하 사이클처럼).
- 방향이 바뀌는 사이클 사이는 동결 구간(간격 60일 이상일 때).
- 마지막 변경 후 180일이 지나면 "동결(진행 중)" 구간을 열고, 그 전이면 마지막 사이클을 진행 중으로 둔다.
- 2008-10 이후 구간만 표시(차트 20년 창과 큐레이션 범위). 자동 경계가 큐레이션 시작일과 같으면 큐레이션 제목·배경을 쓴다.
  실제 변경 이력으로 15개 큐레이션 경계를 그대로 재현하는지 테스트한다.

## 환율 — 큐레이션 이후 자동 탐지
- 큐레이션 구간(2007~2026-09-09)은 손으로 고른 박스권 등이 있어 그대로 두고, 마지막 큐레이션 끝(저점 1,340원) 이후만 지그재그로 탐지한다.
- 지그재그: 직전 고점(저점)에서 8% 이상 반대로 움직이면 그 고점(저점)을 확정 전환점으로 본다. 확정 전환점 사이가 새 국면.
- 마지막 전환점 이후 진행 중 움직임은 5% 이상일 때만 "진행 중" 국면으로 표시(잡음 방지).

## 설명 문구
- 큐레이션이 없는 자동 국면은 Gemini가 제목(12자 안팎)·배경 2~3개를 쓴다. 입력은 그 구간의 데이터 요약과,
  구간이 최근(끝이 120일 이내 또는 진행 중)이면 Google News RSS 헤드라인. 근거 없는 수치·사건은 쓰지 말라고 지시한다.
- 결과는 SectorInsight(`regime_ai:<자산>:<시작일>:<종류>:<끝 또는 open>`)에 저장해 재사용(진행 중 국면은 끝날 때 전체 기간으로 한 번 더 작성). 키·네트워크 실패 시 데이터 기반 기본 문구,
  같은 키 재시도는 6시간 뒤. 화면에는 "자동 감지" 배지와 출처(AI 작성·뉴스 n건 / 데이터 기반)를 표시한다.
- 회의 일정(금통위·FOMC)은 공식 API가 없어 자동화하지 않는다. 목록이 비면 화면에 "일정 갱신 필요"가 뜬다.

## 코드 리뷰·검증 중 고친 것
- 실제 Gemini 호출로 확인하니, 가상의 인하 국면에 오늘 헤드라인(인상 기사)을 따라 "고금리 지속, 추가 긴축 예고"를 썼다.
  프롬프트에 국면 방향을 명시하고, 방향과 반대되는 말(인하 국면의 '인상·긴축' 등)이 있으면 AI 문구를 버리고 기본 문구를 쓴다.
- 진행 중 국면의 AI 문구가 첫날 내용으로 고정되던 문제 → 캐시 키에 끝 날짜(진행 중이면 open)를 넣었다.
- 환율 큐레이션 끝 이후 2% 남짓한 흔들림이 '추세 연장' 국면이 되던 문제 → 5% 이상일 때만.
