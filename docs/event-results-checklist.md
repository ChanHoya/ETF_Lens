# 종합 탭 이벤트 시나리오 — 시점순 배치 + 결과 자동 반영 + 수동 업데이트 (2026-10-05)

## 플랜
사용자 요청: 미국 중간선거를 아래로(시점순) 옮긴다. 이벤트 결과가 나온 뒤 조회하면 결과를 반영해 분석을 갱신하고,
자동 갱신이 안 될 때를 대비해 수동 업데이트 버튼을 둔다.

- 금통위·FOMC·기타 이벤트를 하나의 목록으로 만들고 날짜순으로 보인다. 지난 이벤트는 결과와 함께 30일간 남긴다.
- 결과 판정 방법은 이벤트마다 다르다.
  - 금통위: ECOS 기준금리 일별 변경 이력으로 판정한다.
  - FOMC: FRED 목표금리 상단 변경 이력으로 판정한다.
  - 중간선거처럼 수치가 없는 이벤트: 뉴스 헤드라인과 Gemini로 요약하고, 시나리오 중 어느 쪽인지 고른다. 결과는 DB에 저장한다.
- 결과가 나오면 다음을 갱신한다.
  - 해당 시나리오 행을 강조한다.
  - "직전 주 대비" 시장 반응(원/달러·KOSPI·미 10년물·한 10년물)을 보인다.
  - AI 종합 코멘트를 결과를 반영해 다시 쓴다.
- 자동 경로: 서버 캐시는 10분이다. 화면은 "결과 대기" 이벤트가 있거나 지난 이벤트가 결과 없이 남아 있으면,
  1시간 규칙과 별개로 10분이 지나면 다시 받는다.
- 수동 경로: "결과 업데이트" 버튼을 누르면 POST /api/v1/macro/events/refresh가 실행된다.
  금리 원천을 새로 받고 AI 결과를 다시 확인한 뒤 종합 탭을 다시 계산한다.
