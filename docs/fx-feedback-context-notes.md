# 환율·종합 탭 지인 피드백 반영 — 컨텍스트 노트 (2026-10-05)

## 출발점
- 지인 후기의 핵심은 대시보드가 "원화가 더 강해질 것"처럼 읽힌다는 점이다.
  코드를 확인해 보니 판정 배지·환헤지 판단·종합 탭 달러 배분 근거가 모두 평균 회귀 근거로만 되어 있었다.
  10년 백분위와 실질실효환율이 그 근거이고, 원/달러 상승 쪽 근거는 하나도 없었다.
- 대시보드는 한쪽 견해(평균 회귀 vs 구조적 원화 약세)를 정답으로 삼지 않고 양쪽 근거를 같은 무게로 보여준다.

## 자금 흐름 데이터 (ECOS 301Y013 국제수지, 월간, 백만달러)
- 항목 코드는 다음과 같다. 000000 경상수지, BOPF11000000 직접투자(자산), BOPF21000000 증권투자(자산),
  BOPF12000000 직접투자(부채), BOPF22000000 증권투자(부채).
- BPM6 금융계정 부호: 자산 증가(+) = 내국인 해외투자로 달러 유출, 부채 증가(+) = 외국인 국내투자로 달러 유입.
- 순유입(기본수지 근사) = 경상수지 − 내국인 해외투자(직접+증권) + 외국인 국내투자(직접+증권). 12개월 합으로 본다.
  기타투자·파생·준비자산은 뺀다. 은행 차입과 외환당국 몫이라 "민간의 구조적 흐름"과 성격이 다르다.
- 2026-05~06 경상수지는 월 +390~500억달러로 컸지만, 외국인 증권 순매도도 월 −250억달러 안팎이었다(조회 확인).

## 판정 규칙 (참고용)
- 원화 강세(원/달러 하락) 근거와 원화 약세(원/달러 상승) 근거를 같은 형식으로 나열하고, 차이가 2개 이상일 때만 한쪽 우세로 표시한다.
- 강세 쪽 근거:
  - 10년 백분위 ≥ 80
  - 실질실효환율 ≤ −10%
  - 적정 대비 괴리 ≥ +5%
  - 12개월 순유입 > 0
  - 26주 평균보다 1% 넘게 낮음(하락 추세)
  - 미-한 10년물 금리차 ≤ 0
- 약세 쪽 근거:
  - 10년 백분위 ≤ 20
  - 실질실효환율 ≥ +5%
  - 적정 대비 괴리 ≤ −5%
  - 12개월 순유입 < 0
  - 26주 평균보다 1% 넘게 높음(상승 추세)
  - 금리차 ≥ +1%p
  - 10년 백분위는 높은데(≥70) 3년 백분위는 중간 이하(≤50)
- 마지막 규칙은 지인이 말한 "높은 환율이 새 보통이 됐을 가능성"을 수치로 옮긴 것이다.
- 종합 탭 달러 배분도 같은 목록을 쓴다. 원화 강세 근거는 달러 자산에 −1, 약세 근거는 +1이다.
  두 탭이 서로 다른 말을 하지 않게 하려는 것이다.

## 1단계 실데이터 확인 (2026-10-05)
- 결과는 원/달러 1,343원, 10년 중 73%, 3년 중 18%, 26주 평균 대비 −7.4%다.
  12개월 순유입은 +843억달러로 경상 +2,963, 해외투자 −1,831, 외국인 −289다.
- 판정은 "원화 강세 근거 우세"(강세 3 : 약세 1)다. 약세 쪽 근거는 "3년 기준으론 이미 낮은 편" 하나다.
  규칙을 양쪽으로 바꿨어도 지금 수치는 강세 쪽이 많다. 그래도 지인 견해의 근거가 화면에 같은 형식으로 보인다.
- 로컬 대시보드는 비밀번호 로그인 화면이라 화면 확인은 하지 않았다. 빌드·타입 체크와 API 응답으로 검증했다.
- 프론트 캐시 키를 iprism-fx-v3로 올렸다. 이전 캐시에는 verdict.strong/weak가 없어 그대로 그리면 오류가 난다.

## 2단계 아시아 통화 (2026-10-05)
- 원·엔·위안·대만달러를 모두 달러 대비(FRED DEXKOUS·DEXJPUS·DEXCHUS·DEXTAUS)로 맞췄다.
  교차환율(원/100엔·원/위안)은 두 통화 움직임이 섞여 "원화만 약한가"에 답하지 못한다.
- 비교 기준 시각을 맞추려고 원/달러도 FRED 값을 쓴다(실시간 Yahoo 값 아님).
- 원/100엔은 엔화 자산·여행용 참고 숫자로 카드 하단에만 남긴다.
- 실데이터 1년 변화는 원 −3.7%, 엔 +4.9%, 위안 −5.9%, 대만달러 +4.6%다.
  같은 반도체 수출국인 대만과 원화가 반대로 움직였다.

## 3단계 환헤지 제거 (2026-10-05)
- 지인 의견대로 환헤지 비용 카드, H/UH 점수 판단, DFF·한 3개월 금리 수집을 걷어냈다.
  한국 투자자에게 환노출은 위기 때 자연 헤지가 되고, 헤지 비용 숫자는 판단을 돕기보다 숫자만 늘렸다.
- 대신 판정에 action 한 줄을 둔다. "해외 자산을 지금 사는 데 환율이 돕는가"를 묻는다.
  원화 강세 근거가 우세하면 불리(나눠서 매수), 약세 근거가 우세하면 유리, 그 밖은 중립이다.
- 달러몫/원화몫 분해는 남기고 이름만 "달러 탓(글로벌) vs 한국 고유 요인"으로 바꿨다.
  지인이 ④에서 말한 "달러지수와 함께 봐야 특이함이 보인다"에 답하는 분석이기 때문이다.
- FxFinder(H/UH ETF 쌍 실제 성과 비교)는 성과 분석용으로 그대로 둔다. /discover 화면과 같은 컴포넌트다.

## 4단계 원데이터 겹쳐 보기 (2026-10-05)
- "원/달러는 무엇과 같이 움직이나"의 주 차트를 원/달러(우축)와 비교 지표(좌축) 겹쳐 그리기로 바꿨다.
  비교 지표는 사용자가 고른다(달러지수·금리차·KOSPI·VIX·엔·위안·미 10년물). 지인 말대로 시기마다 맞는 비교 지표가 다르기 때문이다.
- KOSPI는 원/달러와 반대로 움직이는 경우가 많아, 고르면 좌축을 자동으로 뒤집는다. 체크박스로 바꿀 수 있다.
- 수준끼리 겹쳐 보면 추세만 같아도 비슷해 보이는 착시가 있다. 그래서 상관계수 차트는 지우지 않고 "통계로 보기"로 접어 둔다.
- KOSPI 주간은 Yahoo ^KS11(일요일 날짜 봉)이다. W-FRI 리샘플이 같은 주 금요일 행으로 맞춘다는 것을 테스트로 고정했다.
