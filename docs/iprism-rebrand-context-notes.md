# i-Prism 리브랜딩 컨텍스트 노트 (2026-10-04)

## 확정 사항 (사용자 결정)

- 서비스명은 i-Prism(Investment Prism)이다. 텍스트 표기(탭 제목, 문구)는 "i-Prism"을 쓴다.
- 로고는 시안 H2다. 작은 i의 점이 역삼각형 프리즘이고, 왼쪽에서 들어온 흰 빛이 오른쪽으로 부채꼴처럼 퍼진다.
  광선은 끊김 없는 스펙트럼이고, 색 띠가 왼쪽에서 좁다가 오른쪽으로 갈수록 넓어진다(부채꼴 방향).
- PRISM은 i보다 크다. 다섯 색(빨강·주황·노랑·청록·파랑)을 글자 가운데에 두고 이웃 글자와 이어지는 그라데이션으로 칠한다.
- 퍼지는 빛은 분산 투자를 뜻한다.
- 시안 페이지: https://claude.ai/artifact/Me5WWgBSpeGvbPX2AHR4Rs (5차 버전이 확정본)

## 구현 결정

- 글자를 SVG `<text>`로 두면 폰트가 늦게 로드될 때 모양이 흔들리고, 그라데이션 정지점을 글자 중심에 맞출 수 없다.
  그래서 Bricolage Grotesque(wght 800, opsz 96) 윤곽을 fontTools로 path로 바꿔 고정 SVG로 만든다.
- SVG에는 원뿔형 그라데이션이 없어서 광선을 가는 조각(로고 56개, 아이콘 40개)으로 나누고 조각마다 보간 색을 채운다.
  조각은 1.6칸씩 겹쳐 안티앨리어싱 틈을 없앤다. 계산은 생성 스크립트에서 한 번만 하고 결과를 커밋한다.
- 앱은 어두운 화면만 쓰므로 노랑은 어두운 배경용 값(#ffd23f)을 쓴다. i 줄기·프리즘 윤곽은 currentColor라 놓이는 곳의 글자색을 따른다.
- 파비콘과 홈 화면 아이콘은 어두운 둥근 타일 안의 i 마크만 쓴다(글자 없음).
- 도메인 etf-lens.vercel.app과 etf-lens.onrender.com, 외부 API 호출용 User-Agent 문자열은 바꾸지 않는다. 사용자에게 보이지 않고 바꾸면 배포 주소가 깨진다.
