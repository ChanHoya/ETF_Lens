# 금리 탭 장단기 금리차 — 한·미 같은 기준(10년−3년) + 기준 설명 팝업 (2026-10-05)

## 플랜
사용자 지적: 미국은 10년−3개월·10년−2년, 한국은 10년−3년이라 한 차트에서 비교하는 기준이 다르다.
합의한 해결은 아래 네 가지다.
- 한·미 비교선·카드·역전 이력을 "10년−3년"으로 통일한다. 미국채 3년(FRED DGS3)을 새로 받는다.
- 미국 10년−3개월은 "참고(침체 예측 지표)"로 점선 표시하고, 비교선이 아님을 이름에 밝힌다.
- 미국 10년−2년은 화면에서 뺀다(10년−3년과 중복). 종합 탭 유사 국면 특징값(curve)은 내부 계산이라 그대로 둔다.
- 섹션 제목 옆 "기준 설명" 버튼을 누르면 팝업으로 비교 기준과 이유를 설명한다.
