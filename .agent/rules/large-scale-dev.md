# LARGE-SCALE-DEV.MD - 대규모 개발 & 컨텍스트 캐싱 적용 규약

> **목적**: 전체 코드베이스 분석, 전면 재개발, 대규모 리팩토링, 다중 파일 아키텍처 개편 등 장시간 에이전트 루프가 필요한 요청 프롬프트를 받았을 때 비용 최적화(80~95% 절감)와 안전 가드레일을 강제 적용한다.

---

## 🎯 1. 트리거 조건 (Trigger Criteria)

사용자 프롬프트에 다음 키워드 또는 패턴이 포함된 경우 **대규모 개발 모드(Large-Scale Development Mode)**로 자동 판정하고 `gemini-context-caching` 스킬을 의무 적용한다:

1. **전체 코드 분석 기반 개발**: "전체 코드 분석", "코드베이스 전체 분석 후", "레포지토리 전수 조사"
2. **전면 개발 / 아키텍처 개편**: "전면 개발", "전면 개편", "아키텍처 재설계", "신규 모듈 전면 구축"
3. **대규모 리팩토링**: "전면 리팩토링", "대규모 리팩토링", "레거시 코드 전면 교체", "모든 모듈 타입 안전성 강화"
4. **다중 파일 마이그레이션**: "프레임워크 버전 전면 업그레이드", "동기식 -> 비동기식 전면 전환", "전체 테스트 스위트 개편"

---

## ⚡ 2. 대규모 개발 시 필수 실행 규칙 (Mandatory Protocol)

대규모 개발 프롬프트를 수신했을 때 에이전트는 다음 수칙을 준수한다:

1. **스킬 활성화**:
   - `gemini-context-caching` 스킬을 참조하여 고정 컨텍스트(코드베이스 덤프 + 시스템 지침)를 준비한다.
2. **도구 스키마 동결 (Tool Freeze)**:
   - 에이전트 도구(Shell, File I/O 등)는 반드시 캐시 생성 시점(`caches.create`)에 함께 주입하여 동결한다.
   - 추론 턴(`generate_content`)에서는 도구 스키마를 중복 전달하지 않는다.
3. **가드레일 인터셉터 상시 가동**:
   - `AgentGuardrail`을 통해 동일 액션 3회 연속 루프 감지(MD5 서명), 3회 연속 에러 서킷 브레이커, 위험 셸 명령어 사전 차단을 유지한다.
   - 가드레일 위반 시 프로세스를 죽이지 않고 `BLOCKED_BY_GUARDRAIL` 소프트 리플렉션 피드백을 전달하여 모델 스스로 계획을 전환하게 한다.
4. **단계별 모델 믹스 (Dual-Model Phased Strategy)**:
   - 1단계(탐색 및 영향도 분석): `gemini-3.8-flash` 활용으로 초고속·초저비용 트래킹
   - 2단계(대규모 코드 패치 및 생성): 대형 코드 생성 필요 시 `gemini-4-argon` 활용
5. **수명 주기 관리 (Lifecycle Teardown)**:
   - 작업 완료 또는 중단 시 반드시 `caches.delete()`를 호출하여 방치된 캐시 요금이 발생하지 않도록 한다.
